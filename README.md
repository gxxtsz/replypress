# ReplyPress

ReplyPress 是一个开源 Chrome / Edge 扩展。它将 ChatGPT 的单条回答保存为可搜索、带标题大纲的单页 PDF。

## 安装与使用

1. 在 Chrome 中打开 `chrome://extensions/`，或在 Edge 中打开 `edge://extensions/`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」，然后选择项目中的 `extension` 目录。
3. 打开或刷新 `chatgpt.com`。回答生成完成后，点击对应回答下方的「导出 PDF」。
4. 在 ReplyPress 预览页点击「保存 PDF」。在 PDF 阅读器的「大纲」或「书签」侧栏中，点击相应标题即可跳转。需要按 A4 打印时，点击「打印」。

更新源码后，在扩展管理页重新加载 ReplyPress，再刷新已经打开的 ChatGPT 标签页。请从回答下方重新打开导出预览，使正文和图片按新版处理。

## 导出范围

- 打印内容为所选回答。标题、列表、引用、网页链接、代码和表格保留为可复制的内容。页面提供的 MathML 公式使用浏览器排版。
- 预览和 PDF 沿用回答的字号、颜色、间距、表格边框和代码高亮。保存的 PDF 宽 210 毫米，高度随内容变化。页首留 16 毫米，页尾留 17 毫米，左右各留 15 毫米。整条回答连续排在一页，过宽的代码会折行。
- 大纲按回答中的标题层级和顺序生成，最多保留两层书签。正文保留各级标题。重名书签各自指向所在位置，无标题时大纲为空。
- 保留可静态打印的 SVG，包括内嵌图、临时图源和浏览器允许读取的 SVG 链接。PNG、JPEG 和 WebP 优先保留原图。其他已加载的图片可通过像素采集导出，较大的图片会缩小。ChatGPT 已显示的搜图配图可通过其图片 CDN 在预览页重新加载。未加载、超出容量或无法嵌入的图像会显示替代文字。交互组件中的普通正文随回答保留。
- 扩展从当前网页读取可见回答，通过扩展内部消息将一次打印所需的内容传给独立打印页。这个过程在本地内存中完成。关闭打印标签页即可释放其中的回答内容。
- 浏览器会提示扩展需要调试权限。点击「保存 PDF」后，ReplyPress 用该权限让浏览器为当前扩展预览页生成带大纲的 PDF，保存结束后释放调试连接。

## 开发

扩展本身可直接加载。自动测试使用 Node.js 22.13 或更高版本、Playwright Chromium 和 PDF.js。

```sh
npm ci
npx playwright install chromium
npm test
```

测试使用合成对话，覆盖流式回答、会话切换、单条回答提取，以及实际保存的 PDF 的文字、链接、长页排版、矢量图和大纲跳转。
